### Phishing URL Detection Using Machine Learning

### Overview

Phishing is one of the most common cybersecurity threats, where attackers create fraudulent websites that imitate legitimate services to steal sensitive information such as usernames, passwords, banking credentials, and personal data. Traditional phishing detection methods often rely on predefined rules, blacklists, or known attack patterns, making them less effective against newly created phishing websites.

This project develops a complete end-to-end phishing URL detection system by designing and implementing a **custom feature extraction pipeline**. Starting with only the **URL** and **Label** columns from the **PhiUSIIL Phishing URL Dataset** available through the **UCI Machine Learning Repository**, all existing engineered features were discarded. A new machine learning dataset was then generated by extracting lexical, domain, DNS, SSL, WHOIS, and webpage-based characteristics directly from each URL.

The generated dataset (**Phishing_Features.csv**) forms the foundation of the machine learning workflow, which includes data cleaning, exploratory data analysis, preprocessing, feature selection, model development, hyperparameter optimisation, and comprehensive performance evaluation to identify the most effective phishing detection model.
